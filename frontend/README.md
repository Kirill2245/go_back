# Listodo — редактор заметок

SPA-приложение на Vue 3 по практическому заданию №2: заметки со списками дел.

## Стек

- Vue 3
- Vue Router
- Bootstrap 5
- Bootstrap Icons
- SweetAlert2
- Axios

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Бэкенд

Приложение работает с API `http://localhost:8080` (Swagger: `http://localhost:8080/swagger/index.html`).
Перед запуском фронтенда бэкенд должен быть запущен; адрес API задаётся в `src/api/client/api-config.js`.

Используемые эндпоинты:

- `GET /get-tasks` — список задач;
- `POST /create-task` — создание задачи;
- `PATCH /update/{id}` — обновление задачи;
- `DELETE /delete-task/{id}` — удаление задачи;
- `GET /get-small-tasks/{taskID}` — список подзадач задачи;
- `POST /create-small-task` — создание подзадачи;
- `PATCH /update-small-task/{id}` — обновление подзадачи;
- `DELETE /delete-small-task/{id}` — удаление подзадачи.

Запросы выполняются через Axios с интерцепторами: в dev-режиме логируются запросы, ошибки сервера нормализуются в единый формат.

## Страницы

- `/` — главная: список задач и просмотр выбранной задачи;
- `/rate` — оценка приложения;
- `/about` — информация об авторе.

## Функционал

- загрузка списка задач с сервера;
- создание, редактирование и удаление задач (удаление с подтверждением);
- работа с подзадачами выбранной задачи: загрузка, добавление, редактирование и удаление;
- обработка ошибок API с показом сообщения пользователю;
- адаптивная вёрстка для десктопа и телефона.
